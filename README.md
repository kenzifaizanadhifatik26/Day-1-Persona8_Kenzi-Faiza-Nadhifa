## Rangkuman Materi

Materi ini terdiri dari dua bagian besar: **membuat dan mengembangkan** sesuatu dengan bantuan AI, lalu **mengelola perubahan dan berkolaborasi** menggunakan Git dan GitHub.

### 1. Prompt Engineering
- Prompt adalah instruksi yang diberikan kepada model AI untuk mendapatkan hasil tertentu. Bentuknya bisa pertanyaan sederhana, kata kunci, instruksi rumit, sampai potongan kode.
- Konteks sangat menentukan. Prompt singkat seperti "Create student task planner" menghasilkan jawaban yang umum, sedangkan prompt yang lengkap menghasilkan hasil yang jauh lebih sesuai.
- Struktur prompt yang baik terdiri dari **Role** (peran AI), **Task** (tujuan), **Context** (kebutuhan dan batasan), dan **Format** (bentuk output yang diminta).
- Beberapa taktik: pakai kata kerja yang jelas, tentukan panjang dan format output, sebutkan target audiens, sertakan fakta atau data, serta rujuk dokumen atau sumber tertentu.
- Manfaatnya: performa AI lebih baik, bias dan respons yang tidak pantas berkurang, hasil lebih terkontrol dan bisa diprediksi, dan pengalaman memakai AI jadi lebih baik.

### 2. Git dan GitHub
- **Git** adalah sistem version control yang mencatat siapa, kapan, dan apa saja yang berubah pada suatu file. Git dibuat oleh Linus Torvalds pada 2005 dan bekerja secara lokal.
- **GitHub** adalah platform berbasis web untuk menyimpan repository Git secara online sekaligus mendukung kolaborasi.
- **Alur kerja Git:** Working Directory, lalu Staging Area, lalu Git Directory (Repository).
- **Perintah dasar:** `git init`, `git add .`, `git commit -m "pesan"`, `git remote add`, `git push origin main`, dan `git pull origin main`.
- **Setup:** install Git dan VS Code, atur identitas (`user.name` dan `user.email`), lalu buat SSH key (`ssh-keygen -t ed25519`) dan daftarkan ke GitHub supaya koneksi aman.

## Praktik yang Dilakukan

Peserta membuat aplikasi sederhana, yaitu **Student Task Planner**, dengan langkah berikut:

1. Menyiapkan Git, VS Code, dan koneksi SSH ke GitHub, lalu mengecek semuanya (`git --version`, `git config`, `code --version`, `ssh -T git@github.com`).
2. Menulis prompt terstruktur ke platform AI (Claude, Antigravity, atau ChatGPT) untuk membuat web/aplikasi task planner.
3. Menjalankan `git init` pada folder proyek.
4. Melakukan commit dan push ke GitHub.
5. Mengubah proyek, lalu commit dan push lagi untuk melihat riwayat perubahannya.

## Poin Penting

- Semakin jelas dan spesifik prompt, semakin baik hasil dari AI.
- Git bekerja di komputer lokal, sedangkan GitHub menyimpannya secara online untuk kolaborasi.
- Perubahan melewati tiga tahap: working directory, staging area, lalu repository.
- Commit yang rutin membuat setiap perubahan tercatat dan bisa ditelusuri kembali.
